# Security Policy

## Supported Versions

Security fixes are handled on the default branch until the project publishes
versioned releases.

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities.

Use GitHub private vulnerability reporting if it is enabled for this repository.
If it is not enabled, email `bokettodev@gmail.com` with:

- affected version or commit
- reproduction steps
- expected impact
- whether the issue can expose indexed source, model cache paths, or local files

I will acknowledge reports within 7 days when possible and coordinate a fix or
disclosure timeline before publishing details.
